# NASA south-pole resolution comparison

Same geographic footprint, assembled without resizing from native 256px WMTS tiles of NASA LRO_WAC_Mosaic_SPole60_100m_v02. Tile rows and columns 0…2^z−1 cover the full polar square; the declared matrix extends further east beyond this imagery footprint. Downloads: 2026-11-14. JPEG export quality95.

- Level1: 4 tiles →512×512, approximately4280.85m per pixel.
- Level2: 16 tiles →1024×1024, approximately2140.43m per pixel.
- Level3: 64 tiles →2048×2048, approximately1070.21m per pixel.

Source capabilities: https://trek.nasa.gov/tiles/Moon/SP/LRO_WAC_Mosaic_SPole60_100m_v02/1.0.0/WMTSCapabilities.xml

Credit NASA / GSFC / ASU. These are whole-pole overviews, not the highest-detail candidate NAC imagery. App behavior is unchanged.
