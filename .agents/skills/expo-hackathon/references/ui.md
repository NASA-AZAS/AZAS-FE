# 이 프로젝트의 UI 운영 조건

구체적인 코딩·디자인 지침은 references/skills.md의 외부 스킬로 연결한다. 이 파일에는 사용자 조건만 둔다.

- 하루짜리 해커톤 데모. 예쁜 핵심 화면과 동작하는 흐름을 먼저 완성한다.
- 첫 화면에서 정한 색·글자·간격·아이콘을 같은 작은 테마로 재사용한다. 앱 주제를 받기 전 브랜드를 임의로 확정하지 않는다.
- 현실적인 목업 데이터와 반응하는 버튼을 사용하고, 서버가 없어도 핵심 흐름을 시연할 수 있게 한다.
- 기존 의존성을 먼저 쓰며 스타일링 라이브러리나 대형 컴포넌트 체계를 도중에 새로 도입하지 않는다.
- iOS/Android와 SDK 호환성을 확인한다. 웹 미리보기를 네이티브 실기기 검증 완료로 말하지 않는다.
- 별도 디자인 리뷰·시안 경쟁·상시 감사는 사용자가 요청할 때만 한다.
