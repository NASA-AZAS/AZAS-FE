# Planet textures

Local copies from the Three.js example assets, used for the Earth and Moon surfaces:

- Earth: https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg
- Earth normal: https://threejs.org/examples/textures/planets/earth_normal_2048.jpg
- Earth clouds: https://threejs.org/examples/textures/planets/earth_clouds_1024.png
- Moon: https://threejs.org/examples/textures/planets/moon_1024.jpg
- Upstream: https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets

The Sun surface, atmosphere, stars, and orbit lines are generated in the scene.
